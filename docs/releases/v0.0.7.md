# OGBox v0.0.7

An unofficial port of the hakuX original Xbox emulator to the PS5, as a homebrew title
(`PPSA99251`) for a jailbroken console.

> [!IMPORTANT]
> **Piracy is not condoned.** This release contains no games, no Xbox BIOS, boot ROM, EEPROM,
> firmware or keys, and none will ever be provided or linked to. Use only **backups of games you
> own**, made yourself from your own discs.

> [!WARNING]
> **It might still crash or show glitches in games.** This is my build of hakuX for the PS5, not
> the hakuX project's: please report problems here, not to hakuX.

## Added
- **Frame generation** (Settings > Picture and sound > Frame generation, off by default): extra
  frames made between the game's own, so a game at 30 fps looks like 60, and at 120 Hz a game at 60
  looks like 120. Four modes, all from Crux2: Crux2's own motion search, AMD FidelityFX FSR 3
  optical flow, MihawkGen's neural network (by Mihawk) and MihawkGen's Blend. It adds about one
  refresh of delay, and makes nothing for a game that already draws a frame every refresh.
  MihawkGen works up to 4x internal resolution, the other two up to 6x. With it on, the FPS counter
  also shows the pictures a second given to the screen.
- **120 Hz and variable refresh rate** (Settings > Picture and sound > Display refresh rate and
  Variable refresh rate), for a TV that takes them; they take effect at OGBox's next start. Games
  keep their normal speed at 120 Hz.
- **Settings change during a game.** The picture's (aspect, anti-aliasing, upscaling, FPS counter,
  frame generation) apply at once. The others (internal resolution, dithering, ...) put **Apply
  Changes Now** at the top of the quick menu: it saves a state where you are and restarts the game
  from it with the new settings.
- **Your own quick menu:** TRIANGLE in the quick menu shows or hides each entry and moves it, and
  any game setting can be an entry of its own, changed with LEFT and RIGHT. Resume and Quit always
  stay.
- **Boot log in memory** (Settings > Advanced > Boot log, the new default): the log is kept in memory
  and written to `ogbox-boot.log` only when something goes wrong (a crash, a failed game, 15 s with
  no new frame) or when you choose **Save the Log** in the quick menu. "Always written" keeps the old
  behaviour.
- Mods for the game with title ID `54540082` (version 2) and `545400A4` (version 1): 60 fps,
  120 fps, no heat haze, no colour filter, no speed blur, and (`54540082` only) draw distance x2.

## Changed
- A new start screen: the logo fades in and a light crosses it, with "by Press5elect" under it. The
  start notice is gone.
- Settings are written to the drive when the settings or the quick menu close, not at every change.

## Tested
On a PS5, from test builds of this version: the 120 Hz mode (the driver selected 119.88 Hz),
frame generation starting (FSR 3 optical flow at 3x internal resolution), and the new mods (all
applied; the 120 fps one reached about 120 fps at its best). The frame generation passes were also
run on a computer's software Vulkan driver, all four modes making the right in-between pictures.
The last changes (the quick menu's editing, Apply Changes Now, the boot log in memory, settings
written as the menus close, the start screen) were built and checked on a computer but have not run
on a console yet. How fast each frame generation mode runs on the console is not measured.

## Installation
1. Download `OGBox-v0.0.7.zip` below and check it against `OGBox-v0.0.7.zip.sha256`.
2. Copy the `PPSA99251` folder in it to `/data/homebrew/` on the console, replacing the old one.
   0.0.2 and newer also offer this release at its next start (Settings > Updates). Your settings,
   saves, save states and caches stay (`/data/ogbox`, or the data folder you chose).
3. Put your own disc images on the console, a USB drive, extended storage or a network share, and
   read `LEGAL.txt` in the folder.

## Reporting problems
Open an issue on this repository with `ogbox-boot.log` and `ogbox-boot.previous.log` from the
title folder (copy them before you start OGBox again), your firmware version and what you did.
With the boot log in memory, choose **Save the Log** in the quick menu first if the problem isn't a
crash. Never attach or link game files, BIOS files or keys.
