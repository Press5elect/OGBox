# OGBox v0.0.1

An unofficial port of the hakuX original Xbox emulator to the PS5, as a homebrew title
(`PPSA99251`) for a jailbroken console. The first public release.

> [!IMPORTANT]
> **Piracy is not condoned.** This release contains no games, no Xbox BIOS, boot ROM, EEPROM,
> firmware or keys, and none will ever be provided or linked to. Use only **backups of games you
> own**, made yourself from your own discs. Please don't ask for, or post links to, games, BIOS
> files or keys in issues or discussions: they will be removed.

> [!WARNING]
> **Highly experimental.** Expect crashes and freezes. Many games don't start yet, and the ones
> that do can stop, slow down, or lose graphics or sound at any point. OGBox says so every time it
> starts. This is my build of hakuX for the PS5, not the hakuX project's: please report problems
> here, not to hakuX.

## Added
- **Original Xbox games** from XISO (`.iso`, `.xiso`) and CHD images, on the console's storage, USB
  drives, extended storage or SMB / NFS network shares, in a game list with covers.
- **The Xbox's CPU code runs natively** on the PS5's processor; the emulated GPU draws through
  Vulkan at up to 6x the game's resolution, with FXAA, SMAA or SSAA, aspect ratio and overscan
  options.
- **GPU on separate cores** (Settings > Performance, on by default): the emulated GPU's threads
  get processor cores of their own, apart from the Xbox CPU and everything else.
- **A quick menu in game** (OPTIONS): save states (10 slots, each with a picture), the game's
  settings, mods, restart and quit.
- **Settings for each game**, mods, XBE patches (widescreen, 60 fps and other fixes, all off by
  default), cheats and trainers (`.etm`, `.xbtf`; none included).
- **A hard disk manager** for the emulated Xbox hard disk: copy saves out and bring them back in.
- **Network play**: system link on your network or over XLink Kai, and Xbox Live through Insignia.
- **Updates**: OGBox looks for a newer release here at each start (or Settings > Updates), shows
  what is new, and on your OK downloads it, checks it against GitHub's SHA-256, replaces only its
  own files and closes. Your settings, saves, states and games stay.

## Changed
- Since the last bring-up build (0.1.59): settings are in eight sections (Graphics, Performance,
  Audio, Console, Video modes, Network, Game list, Interface) and each one says what it does and
  its default; the splash no longer shows "X to skip" (CROSS or CIRCLE still skips it). Settings
  you already saved carry over.

## Fixed
- **A crash a few seconds into a game** that sets a gamma ramp and then changes its display's size
  (one I tested goes from 640 x 960 to 640 x 480 at its first frames), at any resolution scale:
  the gamma pass freed a picture's view twice. hakuX-lr has the same fix.
- A trainer's help line for another release of its game is no longer cut short.

## Tested for this release
- **On my console**, the GPU threads on cores of their own (with the last bring-up build and the
  `boot.txt` switch this release turns into the setting) made the game I tested with run much
  better than with every thread sharing the same cores. I didn't record frame-rate numbers.
- **The crash fixed above**: on my console the game ended 4.5 s in, in four runs (6x and 1x, with
  and without the enhancements, either audio processing, and with 0.1.58), each time in the
  memory allocator on the GPU's thread; 0.1.58's stack showed the gamma pass's second free.
- **Not run on the console yet: this exact build.** What it adds over those runs is the start-up
  notice, the settings layout, the setting itself, the updater and the fix. It builds cleanly and
  passes the release checks (every part's licence and source).
- **On a PC**: the updater's own test (737 checks, with memory-error checking) installs this
  release's ZIP over an older folder and keeps the user's files; against GitHub itself it asks
  for the releases and reads the answer. The emulator core in this build (unchanged since the
  last bring-up build) passes OGBox's own Xbox test program: 76 tests, with 4 KB and 16 KB pages,
  from an ISO and from a CHD.
- **Full DSP** audio processing (Settings > Audio) is off by default and hasn't been measured on
  the console.
- In an early build, a game froze with the GPU threads on their own cores. If one freezes or
  stutters, turn **GPU on separate cores** off in that game's settings.

## Installation
1. Download `OGBox-v0.0.1.zip` below and check it (SHA-256 at the end of these notes).
2. Copy the `PPSA99251` folder in it to `/data/homebrew/` on the console. With the payload loader
   (elfldr) running, OGBox can also see USB drives and extended storage.
3. Later versions install themselves (Settings > Updates), or replace the folder by hand. Your
   settings, the Xbox hard disk (your saves), save states and caches are kept outside it
   (`/data/ogbox`, or the data folder you chose).
4. Put your own disc images on the console, a USB drive, extended storage or a network share, and
   read `LEGAL.txt` in the folder.

## Reporting problems
Open an issue on this repository. Include `ogbox-boot.log` and `ogbox-boot.previous.log` from the
title folder (copy them before you start OGBox again: only the run before is kept), your firmware
version and what you did. Never attach or link game files, BIOS files or keys.
