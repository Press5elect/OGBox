## Added
- **HD texture packs and texture dumps** (Settings > Picture > Textures, per game): each texture the
  game uses can be saved once (compressed ones as DDS, the rest as PNG) and replaced by a PNG or DDS
  file at 1 to 8 times its size, named after the texture's code. A replacement goes to the GPU once
  and is shared by every texture with that code.
- **Sound mixing** (Settings > Advanced): Default is the game's own sound program's mix, as on the
  console; Fast is OGBox's own mix of the voices.
- **Saves from a console**: Xbox games sign their saves with keys of the console's, which OGBox
  doesn't have, so a save made on an Xbox, in xemu or by an Xbox 360's backward compatibility was
  refused by its game. Put your own dumps in the data folder's `console` folder:
  - `mcpx.bin` (the MCPX 1.0 boot ROM) and `bios.bin` (that console's BIOS);
  - for saves locked to the console, that console's `eeprom.bin` (or an Xbox 360's HD key, as 32
    hex digits, in `hdkey.txt`).

  When a game starts, OGBox re-signs its saves that the other console signed and leaves every other
  file as it is. The keys are read then and never kept; OGBox includes none.
- **Game fixes from GitHub at start** (Settings > Interface > Download game fixes at start, on by
  default): the newest mods and XBE patches are fetched when they differ from the title folder's,
  so a fixed game needs no new OGBox. A notice says which games got fixes.
- **The hard disk manager and the sync place**: **Saves on <place>...** lists the saves on the share
  or USB drive the saves are kept in sync with, and **Delete** can delete a save there too, so the
  next sync doesn't bring it back.
- OGBox's own **60 FPS patches** for `4B4E0004` (versions 1 and 3, in place of the imported ones),
  `4541009E` (v1), `4541007B` (v7), `45410047` (both version 1 releases), `45410071` (v1) and
  `4541005A` (v1); Nemesis2000's widescreen patch for `45410047`, ported to version 1.
- A patch can be for several releases of a game, and is then listed once.
- A game fix for `45410049` (v1): smooth frame pacing.

## Fixed
- `4B4E0034`: white flashes, a white ground, blurred rectangles in attacks and long black shadow
  spikes. Render targets that share memory now land in the order they were drawn, only the
  memory's last writer lands, and a swizzled target's surface clip limits the draws into it (the
  shadow map's border stays clear).
- Uneven frame pacing (61-62 fps on a 120 Hz panel) when the panel's period was first measured
  wrong: it is now taken again from the median of the vsync gaps.
- `41560020` (v3, v5) and `4156004E` (v2) with the 60 FPS patch: movement was uneven while the
  counter showed 60. Each frame's step is now the time due, rounded to the picture's 120 Hz
  pickups, with the rest carried to the next frame, so the game's time stays the real time. The
  patch's earlier floor of 16 ms had also made the game run a few per cent fast.
- Particles and billboards that came and went (`4D530039`: waterfalls, wheel dust, roadside
  trees): a game that sends `BEGIN` again before each chunk of a draw and `END` once had only its
  last chunk drawn.
- A game's first start could stop with a disc error or a black screen while it copied files to a
  cache drive (`4D530039`): a rename refused while the file was still being written or closed is
  tried again.
- The balance of voices, music and effects in games whose sound program does the mixing.

## Tested
On a PS5, from test builds of this version:
- `4B4E0034`: no white flashes, no white ground, no blurred rectangles in attacks and no shadow
  spikes; steady frame pacing on a 119.88 Hz panel.
- Frame rates in play (medians of 5-second counts, 119.88 Hz panel):
  - `4B4E0034`: 59.9 fps;
  - `4553000F`: 59.7 fps;
  - `41560020`: 59.9 fps;
  - `4D5300D1`: 59.5 fps.
- `4541005A` and `45410071`: races at 59.9 fps.
- `45410049`: fights and cut scenes smooth.
- Texture dumps.
- The final test builds of this version ran as intended in the owner's games.
- On the PC: every PC test (`tests/run-pc-tests.sh --fetch`), among them new ones for the save
  re-signer; hakuX-native's render-target tests (`tests/cohalias`, 108 runs, and `tests/coh16k`);
  and the `41560020` and `4156004E` patches' rewritten code, run at the game's own addresses
  against a model of the new step over 21000 frames.

## Installation
1. Download `OGBox-v1.0.2.zip` below and check it against `OGBox-v1.0.2.zip.sha256`.
2. Copy the `PPSA99251` folder in it to `/data/homebrew/` on the console, replacing the old one.
   0.0.2 and newer also offer this release at their next start (Settings > Updates). Your
   settings, saves, save states and caches stay where they are (`/data/ogbox`, or the data folder
   you chose).
3. Put your own disc images (or extracted games) on the console, a USB drive, extended storage or
   a network share. Read `LEGAL.txt` in the folder.

## Reporting problems
Open an issue on this repository and include:
- `ogbox-boot.log` and `ogbox-boot.previous.log` from the title folder (copy them before you
  start OGBox again);
- your firmware version;
- what you did.

If the problem isn't a crash, choose **Save the Log** in the quick menu first. Never attach or
link game files, BIOS files or keys.
