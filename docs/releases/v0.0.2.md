# OGBox v0.0.2

An unofficial port of the hakuX original Xbox emulator to the PS5, as a homebrew title
(`PPSA99251`) for a jailbroken console.

> [!IMPORTANT]
> **Piracy is not condoned.** This release contains no games, no Xbox BIOS, boot ROM, EEPROM,
> firmware or keys, and none will ever be provided or linked to. Use only **backups of games you
> own**, made yourself from your own discs.

> [!WARNING]
> **Highly experimental.** Expect crashes and freezes. This is my build of hakuX for the PS5, not
> the hakuX project's: please report problems here, not to hakuX.

## Added
- Game list tabs, **Internal / USB / Network** (L1 / R1). CIRCLE at a tab's places asks before
  closing OGBox.
- A game with a "Quit, and save where I am" state asks when it starts: go on from there, start
  from the beginning, or go back.
- Quick menu > **Log what the GPU draws**, for a graphics problem's report.
- Mods, patches, cheats and trainers are checked against the disc's release: one made for another
  release of the game is greyed out.

## Changed
- When a game starts another of its XBEs, its last frame stays on screen instead of the "core is
  running" screen.
- The dashboard row shows only when the Xbox hard disk has a dashboard (Settings > Game list says
  when it hasn't).
- Compile shaders in the background is off by default.
- Covers: the file's own release first, then the other records of its title ID.
- One boot log for the whole session, written to the disk every 2 s.

## Fixed
- OGBox, and sometimes the whole console, crashing when a game was quit or OGBox was closed.
- A game freezing while it loads a level (it ran out of open files).
- A game running at 2 to 6 fps (hard disk cache writes held the Xbox CPU; its GPU interrupt
  handler waited for results that never come).
- Games dropping to 30 fps in busy scenes (the emulated GPU's per-draw overhead).
- Loading screens showing only their bar.
- Games stopping at their menus (the processor now identifies itself as the Xbox's Pentium III).
- A game running out of memory at a level's load.
- A leaning or white logo, trails behind a blur, file times on the Xbox hard disk, and xemu's
  fixes since hakuX's fork (fog, clear alpha, nearest readback, push buffer DMA control).

## Tested
On my console, with the build before this one (the same code; only the notes differ): the game I
tested the frame rate with ran at 2 to 4 fps before these fixes and holds 59 to 60 fps in its levels now,
up to about 8,800 draws a frame; a heavier scene can still dip. Its loading screens' picture is
copied into their backdrop. Four games ran in that session without a crash, and every exit ended
normally. A level that froze while loading now loads. The build passes the release check (every
part's licence and source).

## Installation
1. Download `OGBox-v0.0.2.zip` below and check it against `OGBox-v0.0.2.zip.sha256`.
2. Copy the `PPSA99251` folder in it to `/data/homebrew/` on the console, replacing the old one.
   0.0.1 also offers this release at its next start (Settings > Updates). Your settings, saves,
   save states and caches stay (`/data/ogbox`, or the data folder you chose).
3. Put your own disc images on the console, a USB drive, extended storage or a network share, and
   read `LEGAL.txt` in the folder.

## Reporting problems
Open an issue on this repository with `ogbox-boot.log` and `ogbox-boot.previous.log` from the
title folder (copy them before you start OGBox again), your firmware version and what you did.
Never attach or link game files, BIOS files or keys.
